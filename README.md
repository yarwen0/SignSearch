# SignSearch

Sign-to-dictionary retrieval for American Sign Language. A clip is represented by upper-body pose and hand landmarks, then ranked against a fixed vocabulary. This is isolated-sign lookup, not sentence translation or a substitute for an interpreter.

## Data and license

This experiment uses a seeded random subset of 250 glosses present in all official [ASL Citizen](https://www.microsoft.com/en-us/research/project/asl-citizen/) splits. Selection seed: 0. The official signer assignments are preserved; tests check for signer and clip overlap.

Videos are personal data. Do not redistribute the dataset, landmarks, or split manifests. The pipeline uses HTTP ranges to retrieve the member list, official split metadata, and selected videos without downloading the complete archive. Downloaded videos are deleted only after successful landmark extraction. Dataset files, landmarks, MediaPipe model files, and checkpoints are ignored by Git. Failed clips are logged locally; training refuses incomplete required splits.

## Method

MediaPipe Tasks HandLandmarker and lite PoseLandmarker run in VIDEO mode. Coordinates are centered at the shoulder midpoint and divided by shoulder width in pixel space. Missing groups remain zero and have explicit masks; missing shoulder anchors are interpolated within a clip. All decoded frames are processed; long clips are sampled and short clips padded to 64 frames. Features are saved locally as float16.

The transformer projects 101 input features to width 192, uses 4 encoder layers and 4 attention heads, learned positions, masked mean pooling, and a 250-class head. A pooled mean/standard-deviation MLP is the baseline. Training uses AdamW, cosine scheduling, label smoothing 0.1, fixed seed 0, and spatial, speed, and mirrored-hand augmentations. Only validation top-1 selects the learning rate and stopping epoch. All hyperparameters and curves are retained in `results/`.

## Reproduce

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/prepare.py
.venv/bin/python -m pytest
.venv/bin/python train.py
.venv/bin/python evaluate.py
.venv/bin/python scripts/update_readme.py
```

After completing the experiment, rank an isolated signing clip with `.venv/bin/python search.py /path/to/clip.mp4`. The command preserves the original clip, deletes its temporary copy and query landmarks, and prints ranked glosses with model probabilities. These probabilities are not calibrated confidence estimates. Exported model files and the local gloss vocabulary must be present.

`results/environment.txt` records the packages used for this run. `results/prepare.log` and `data/extraction.jsonl` retain extraction evidence; the latter is ignored because it contains dataset identifiers. Curves record every training epoch. Raw prediction arrays are retained locally and ignored. `results/test_started.json` freezes the final evaluation boundary; do not remove it or tune on the test results. Re-running evaluation after completion prints the existing metrics. `scripts/run_pipeline.py` coordinates preparation, selection, evaluation, and README generation without evaluating test during training.

## Limits

This is a 250-sign subset and is not comparable with the full-vocabulary numbers in the ASL Citizen paper. It uses pose and hand coordinates only, omitting facial expression, appearance, and depth. Horizontal flipping is a training assumption and can change lexical meaning for some signs. MediaPipe errors, occlusion, missing hands, camera framing, and signing variation affect retrieval. The provided dictionary glosses are identifiers rather than translations of all possible meanings.

Held-out signer top-1 varies from 0.8129770992366412 to 0.9298892988929889, with median 0.875; the complete per-signer counts and scores are in `results/metrics.json`. The clip bootstrap interval does not capture signer-population uncertainty. These measurements describe this dataset subset and recording conditions, not general accessibility effectiveness.
